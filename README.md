# 케어 에이전트 (Care Agent: Proactive Vehicle Care)

차가 먼저 알아채고 해결까지 이어 주어, 차 관리에 드는 운전자의 수고를 말 한마디로 줄이는 차량 케어 에이전트입니다.

- 타이어 공기압이 경고 수준에 가까워지면 경고등이 켜지기 전에 공기 보충과 가까운 정비소를 안내합니다.
- 연료·배터리로 목적지(평소 주유소, 퇴근길 집)까지 갈 수 있는지 판단하고, 부족하면 주유소·충전소 경유를 제안합니다.
- 고속도로에서 배터리가 부족하면 휴게소로 오는 찾아가는 충전을 제안합니다.
- 정비소에 머문 뒤 다음 정차 때 정비 내용을 묻고 기록하며, 다음 교환 시기 전에 알리고 정비소 예약까지 이어 줍니다.
- 어떤 동작이든 운전자가 승인한 뒤에만 실행합니다.

## APK

`apk/` 폴더의 release 빌드를 설치합니다.

## 테스트 환경

- Pleos Connect Emulator v2.1.0 (Android Automotive, API 34), AVD RAM 4GB 이상 권장
- 화면 규격: 2560 × 1440, 160dpi (에뮬레이터 기본값)
- 에뮬레이터 Virtual Console 사용 (차량 신호를 가상으로 넣는 데 씁니다)
- 별도 계정·키 설정은 필요 없습니다.

## 실행 방법

1. 에뮬레이터를 켠 뒤 APK를 설치합니다. `-g`는 권한과 화면 위에 표시(떠 있는 창) 권한을 함께 허용합니다.

   ```bash
   adb install -g apk/개인참가_케어에이전트_release.apk
   ```

2. 하단 바의 케어 에이전트 아이콘(체크 표시)을 엽니다. 화면 위쪽에 '지켜보는 중'이 보이면 감지가 켜진 상태입니다.
3. 위쪽 띠의 **상황 체험 창 켜기**를 누른 뒤 내비게이션(지도) 화면으로 돌아갑니다.
4. 지도 오른쪽 위 **상황 체험** 창에서 상황 버튼을 누르면 해당 상황이 처음부터 진행됩니다.

   | 버튼 | 상황 |
   |---|---|
   | 1 타이어 | 주행 중 앞바퀴 두 개 공기압이 낮아짐 → 공기 보충 안내 → 정비소 안내 |
   | 2-A 주유 | 플러그인 하이브리드, 연료 부족 → 평소 주유소까지 갈 수 있는지 안내 |
   | 2-B 퇴근길 충전 | 전기차, 퇴근길에 집까지 배터리 부족 → 충전소 경유 |
   | 2-C 찾아가는 충전 | 전기차, 고속도로에서 배터리 부족 → 휴게소 찾아가는 충전 요청 |
   | 3 방문 기록 | 정비소에 머문 뒤 다음 정차 때 정비 내용 확인·기록 |
   | 4 교환 시기 | 엔진오일 교환 시기 전 알림 → 원하는 지역 정비소 예약 |
   | 처음 상태로 | 체험 데이터를 지우고 문제 없는 기본 상태로 되돌림 |

5. 에이전트가 음성으로 안내하면, 상황 체험 창 왼쪽의 음성 창에서 선택지를 눌러 답합니다. 실제 제품에서는 말로 대답합니다.

상황 체험 창 아래에는 에이전트가 거친 판단 단계와 판단 근거가 표시됩니다. 상황 체험 창과 음성 창은 시연용 창이며 실제 차량 화면에는 나오지 않습니다.

### 체험 환경의 제약

- 차량 신호는 Virtual Console의 가상 신호와 앱 안의 시뮬레이션 값(바퀴별 공기압, 연료 등 에뮬레이터가 지원하지 않는 값)입니다.
- 장소(데모 정비소·주유소·충전소·휴게소), 평소 귀가·주유 패턴, 찾아가는 충전·정비소 예약 응답은 체험용 데이터이며 외부에 실제로 요청하지 않습니다.
- 에뮬레이터 내비의 차 위치는 고정되어 있습니다.

## 구조

| 경로 | 내용 |
|---|---|
| `core/domain` | 차량 상태 판단, 대화 흐름, 승인, 정비 기록·교환 주기 계산 (순수 Kotlin) |
| `integrations/pleos` | Pleos SDK 연동: Vehicle, FusedLocation, TextToSpeech, SpeechToText, NaviHelper |
| `app` | 상시 감지 서비스, 앱 화면(Compose), 상황 체험 창·음성 창, Gleo AI 연동 스키마 |

## 빌드

JDK 17, Android SDK(compileSdk 35)가 필요합니다.

```bash
./gradlew :app:assembleDebug
./gradlew :app:assembleRelease   # 서명 설정: 환경변수 CARECARE_SIGNING에 서명 정보 properties 파일 경로
```
